
# LATEX VISION: Elastic Reality Suite
*(Built on SVI 2.0 Pro Architecture)*

**Latex Vision** is the public-facing "Director Console" for the **SVI 2.0 Pro** framework. It is a professional generative video platform designed to mold reality with synthetic precision.

While the user sees an elegant interface for "Elastic Synthesis," the backend relies on the robust **SVI 2.0 (Stable Video Infinity)** pipeline to ensure temporal coherence and identity locking across long-form video generations.

## 🌌 Core Philosophy: The Latex Metaphor
1. **Elastic Time:** Unlike rigid timelines, our engine treats time as a stretchable dimension. Scenes can be extended, looped, and morphed without breaking the narrative thread.
2. **Synthetic Skin (Identity Lock):** Just as latex conforms perfectly to a form, our **Identity Matrix** wraps your characters in a consistent visual layer. 
3. **Molding > Prompting:** We don't just "ask" the AI. The **Synthetic Director** (Cognitive Layer) acts as a sculptor, translating abstract intent into precise tensor manipulations.

## 🛠 Under the Hood (SVI 2.0 Pro)
Developers working on this repo should understand the underlying mechanics hidden from the user:
- **Engine:** SVI 2.0 Pro (Custom implementation of Wan 2.2 MoE).
- **Protocol:** FMLF (First-Middle-Last Frame) for seamless clip stitching.
- **Data Structure:** Directed Acyclic Graph (DAG) stored in IndexedDB.
- **Cognitive Driver:** Gemini 3 Flash acting as the "Director Agent".

## 📦 Quick Start
1. **Install dependencies:** `npm install`
2. **Set API Keys:** Configure `process.env.API_KEY` (Gemini) and RunPod secrets.
3. **Launch Studio:** `npm run dev`
4. **Access:** Open `localhost:5173` to enter the Vision Terminal.
